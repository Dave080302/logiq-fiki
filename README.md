# LogiQ · Fiki

[Project journal](https://andrei-27.github.io/logiq-fiki/) · [M4 prototype](https://andrei-27.github.io/logiq-fiki/news.html) · [UX & interview guide](https://andrei-27.github.io/logiq-fiki/ux.html)

## Main files

- `index.html`: milestone journal and project overview.
- `news.html`, `news.js`, `news-data.js`, `m4.css`: M4 news-verification UX.
- `ux.html`, `assets/m4/flow.svg`: research, persona, stories, flows, and feedback tasks.
- `landing.html`: current product introduction.
- `wireframes.html`, `landing-m3.html`: preserved M3 prototype and landing page.
- `interviews.html`, `findings.html`, `transcripts/`: existing research evidence.

Run `python3 serve.py` and open http://localhost:8000/. No build or installation is needed. The preview server supports the byte-range audio requests Safari needs.

The M4 demo uses fictional articles and curated official sources. It does not check real pages or arbitrary text. Feedback stays in memory until reset or reload. Try all four scenarios, cancellation, browser Back/Forward, source details, clipboard fallback, phone layout, and feedback validation.

UX feedback interviews are pending. Confirm or supplement the milestone’s three face-to-face interviews from the main segment; do not report prototype feedback as collected research.

GitHub Pages serves the repository root from `main`. Original Google references and the Figma Make project were not edited.
